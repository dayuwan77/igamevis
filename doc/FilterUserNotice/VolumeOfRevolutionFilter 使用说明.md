# VolumeOfRevolutionFilter 使用说明

## 1. 功能概述

**VolumeOfRevolutionFilter** 把输入的**每一个单元**绕指定轴扫掠，生成旋转体。
语义对齐 VTK/ParaView 的 `vtkVolumeOfRevolutionFilter`（本仓库用 VTK 9.7 / ParaView 6.2.0 逐点逐单元比对过）：

- 二维截面单元（三角形/四边形/多边形）→ **体单元**（楔形体/六面体/多面体）；
- 一维轮廓（线段/折线）→ 四边形面片；
- 顶点单元 → 线段。

因此“生成体单元”的前提是**输入是二维截面**（例如花瓶的剖面、垫圈的截面）；只给一条一维轮廓时，
输出仍是面片——这与 ParaView 的行为完全一致（ParaView 的点→线、线→四边形的映射同样是升一维）。

输入支持 `UnstructuredMesh`、`SurfaceMesh`、`StructuredMesh`，输出统一为 `UnstructuredMesh`。
与旧版“先提取轮廓边、再旋转成外壳”的实现不同，本版本不再丢弃面片单元，也不再以共线/贴轴等几何理由拒绝输入。

---

## 2. 单元类型映射（与 ParaView 一致）

| 输入单元 | 输出单元 | 说明 |
| --- | --- | --- |
| `IG_VERTEX` | `IG_LINE` | 点扫成线；**不会**把无连接的点云自动串起来 |
| `IG_LINE` / `IG_POLY_LINE` | `IG_QUAD` | ParaView 输出四边形，不是三角形；折线按段展开 |
| `IG_TRIANGLE` | `IG_PRISM`（VTK 的 WEDGE） | 体单元 |
| `IG_QUAD` | `IG_HEXAHEDRON` | 体单元 |
| `IG_POLYGON` / `IG_FACE` | `IG_POLYHEDRON` | 体单元，连接表用核心约定的面编码 |
| 体单元（四面体/六面体/棱柱/金字塔/多面体/`IG_VOLUME`） | —— | 只要输入里存在拓扑维数大于 2 的单元就**整体停止**并报错 |
| 其他（二阶/拉格朗日等） | —— | **明确警告并跳过**，不静默忽略；全部被跳过时报错 |

---

## 3. 调用方式

UI 未改动：

1. 加载模型（要做成实体，请加载**二维截面**，如三角/四边形面片）。
2. 菜单 **“算法处理”** → **“旋转体生成 (Volume of Revolution)”**。
3. 参数对话框：分段数（≥3）、旋转角度（度）、轴方向、轴上一点。
4. 点击确定，输出名为 `<输入名>_revolution` 的 `UnstructuredMesh`。

---

## 4. 参数说明

| 参数 | 说明 | 过滤器默认值 | UI 默认值 |
| --- | --- | --- | --- |
| 分段数 | 旋转角度被等分的段数（≥3） | 12（与 VTK 一致，每 30 度一段） | 36 |
| 旋转角度 | 弧度；任意有限非零值，支持负角 | 2π（整圈） | 360 度 |
| 轴方向 | 非零有限向量 | (0, 0, 1) | (0, 0, 1) |
| 轴上一点 | 有限坐标 | (0, 0, 0) | (0, 0, 0) |

与 VTK 相同，|角度| 恰好为一整圈时首尾层合并（不产生重复的接缝点），否则多生成一层。
角度在 UI 中以度输入，内部换算为弧度。

---

## 5. 与 ParaView 的对齐方式

移植逐行对应 `vtkVolumeOfRevolutionFilter`：

- **点**：层优先排布，`index = layer * 输入点数 + 输入点号`；与 VTK 一样复制**全部**输入点
  （包括未被单元引用的点）。
- **旋转公式**：与 VTK 相同的 Rodrigues 形式
  `out = (in-p)·cosθ + dir·(dir·(in-p))·(1-cosθ) - ((in-p)×dir)·sinθ + p`。
- **单元**：三角形/四边形沿用“两层同序”连接，折线/多边形按 VTK 的展开方式
  （折线拆段、多边形编码为 `[面数, 面n点数, 面n点号..., ...]`）。
- **属性**：点属性按层复制；每个生成单元继承其**来源单元**的单元属性。

验证方式：用相同输入分别跑 ParaView 6.2.0 的 `vtkVolumeOfRevolutionFilter` 与本过滤器，
比较输出点数、全部点坐标、单元数、单元类型与完整连接表（多边形比较多面体面编码），
9 个用例（四边形/三角形/多边形、线段/折线、顶点、整圈/180 度/90 度、混合输入）逐项一致。

## 6. 注意事项

1. **要有体单元，输入必须是二维截面。** 只给一维轮廓时输出四边形面片，和 ParaView 一样。
2. **体单元输入会被整体拒绝**：只要输入里有一个拓扑维数大于 2 的单元，就不再处理，
   而不是“挑出能用的部分”。失败原因见 `GetMessage()`。
3. **不支持的单元不会被静默忽略**：执行成功时会返回跳过计数与首个被跳过的类型
   （`GetMessage()` 非空，日志同时给出 warning）。
4. **不做共线/退化检查**：旧版的“三重循环共线判定”“轮廓与轴平行”“所有点落在轴上”等拒绝逻辑已删除，
   与 VTK 一致——这类输入会产生退化单元，而不是报错。
5. **单元定向随输入绕向变化**：与 ParaView 相同（VTK 的楔形体与六面体面表约定本身互为反向），
   若渲染法向朝内，把输入截面的绕向反过来即可。
6. **整圈扫掠**：首尾层合并，模型在拓扑上封闭（截面封闭时得到封闭实体）；非整圈时两端不封盖。
7. **执行失败后的状态**：失败时输出被清空（不保留上一次结果），原因见 `GetMessage()`。
