# VolumeOfRevolutionFilter 使用说明

## 1. 功能概述

**VolumeOfRevolutionFilter** 是一个旋转体生成过滤器，用于将输入的 **2D 轮廓（曲线或曲面边界）** 绕指定的旋转轴旋转指定角度，生成一个 **3D 表面网格（UnstructuredMesh）**。  

该过滤器支持从多种输入类型（`UnstructuredMesh`、`SurfaceMesh`、`StructuredMesh`）中提取轮廓线，并自动复制原始轮廓上的点属性和单元属性到旋转后的网格中，实现属性传递。

该功能适用于生成轴对称模型、旋转体几何建模以及基于轮廓的仿真前处理等场景。

---

## 2. 调用方式

### 2.1 图形界面

1. 在 **iGameVis** 中加载一个 2D 轮廓模型（支持曲线或平面网格）。
2. 在顶部菜单栏选择 **“算法处理”** → **“旋转体生成 (Volume of Revolution)”**。
3. 弹出参数对话框，设置以下参数：
   - **分段数**（Resolution）：将旋转角度等分的段数（≥3，越大网格越细）。
   - **旋转角度（度）**：绕轴旋转的总角度（例如 360° 或 180°）。
   - **轴向 X/Y/Z**：旋转轴的方向向量（至少一个分量非零）。
   - **轴点 X/Y/Z**：旋转轴通过的一个点（默认原点）。
4. 点击 **“确定”**，过滤器执行，生成的 3D 表面网格自动添加到模型树中，名称后缀为 `_revolution`。

---

## 3. 参数说明

| 参数           | 类型         | 说明                                               | 默认值（UI） |
| -------------- | ------------ | -------------------------------------------------- | ------------ |
| **分段数**     | 整数         | 旋转角度被等分的段数，最小值 3。值越大网格越精细。 | 36           |
| **旋转角度**   | 浮点数（度） | 绕轴旋转的总角度（如 360、180），支持任意正负值。  | 360.0        |
| **轴向 X/Y/Z** | 浮点数       | 旋转轴的方向向量分量，至少一个非零。               | (0, 0, 1)    |
| **轴点 X/Y/Z** | 浮点数       | 旋转轴经过的点的坐标。                             | (0, 0, 0)    |

> **注意**：角度在内部转换为弧度，支持完整圆周旋转（360°）时，首尾顶点会自动合并，避免重复点。

## 5. 注意事项

1. **输入类型支持**  
   - `UnstructuredMesh`：需包含线段（`IG_LINE`）单元，或至少有两个点（按顺序连接）。
   - `SurfaceMesh`：提取其 **边界边**（即只被一个面片使用的边）作为轮廓。
   - `StructuredMesh`：若为 1D 曲线（维度为 `n×1×1`）则直接顺序连接所有顶点；若为 2D 曲面（`n×m×1`），则提取其外边界边。
   - 若输入为其他类型，过滤器会报错。

2. **轮廓要求**  
   - 轮廓应为 **开环或闭环** 的曲线，旋转后会自动生成侧面三角形。
   - 若轮廓存在自交或重叠，可能产生非流形网格，请确保输入轮廓简单有效。

3. **旋转轴与点**  
   - 轴方向向量不能为零向量（至少一个分量非零）。
   - 轴点用于定义轴的位置，通常取原点或轮廓中心。

4. **属性复制**  
   - 所有 **点属性**（标量/向量）会按原始点的顺序复制到旋转后的每一层点（每层对应一个旋转角度）。
   - 如果输入提供了 **单元属性**（仅当轮廓来自 `SurfaceMesh` 或 `StructuredMesh` 且每个边关联一个面片时），则每个生成三角形会继承对应面片的单元属性值。
   - 属性类型（`FloatArray`、`DoubleArray`、`IntArray` 等iGame框架支持的类型）均被支持。

5. **完整圆周的特殊处理**  
   - 当旋转角度为 360°（或 -360°）时，最后一层点会复用第一层点的索引，避免产生重叠顶点，确保网格封闭。

6. **网格质量**  
   - 轮廓上若存在位于轴上的点（`r=0`），该点旋转后始终在轴上，相邻三角形会退化为三角形（非退化），算法已处理该情况。
