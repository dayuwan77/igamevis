# PassArraysFilter 使用说明

## 1. 功能概述

**PassArraysFilter** 是一个数据筛选过滤器，用于从输入网格（如 `UnstructuredMesh`、`SurfaceMesh`、`VolumeMesh`、`StructuredMesh` 等）中，**只保留用户指定的属性数组**（点属性和单元属性），并生成一个新的数据对象。  

未选择的属性将被丢弃，且所有保留的属性均通过**深拷贝**独立存储，确保与原数据互不影响。

该过滤器适用于需要精简数据集、减少内存占用，或仅保留特定字段进行后续处理的场景。

---

## 2. 调用方式

1. 在 **iGameVis** 中加载一个网格模型（支持多种网格类型）。
2. 在顶部菜单栏选择 **“算法处理”** → **“传递过滤数据数组 (Pass Arrays)”**。
3. 弹出对话框，列出当前模型所有可用的属性（点属性和单元属性）。
4. 勾选需要保留的属性（默认为全选），至少保留一个。
5. 点击 **“确定”**，过滤器执行并生成新模型，新模型自动添加到模型树中，名称后缀为 `_filtered`。

## 4. 注意事项

1. **必须至少选择一个属性**：若对话框中未勾选任何属性，过滤器会提示并拒绝执行。
2. **属性名称必须精确匹配**：过滤器通过属性名称（字符串）进行匹配，大小写敏感。
3. **支持多种数组类型**：内部实现了对 `FloatArray`、`DoubleArray`、`IntArray`、`UnsignedIntArray`、`CharArray` 等iGame框架支持类型的深拷贝。
4. **深拷贝隔离**：输出数据与输入数据完全独立，修改输出不会影响输入。
5. **不支持的数据类型**：若输入属性类型未在深拷贝支持列表中，过滤器会报错并返回空指针（当前支持所有标准 `iGame` 数组类型）。
6. **性能考虑**：当模型规模较大时，深拷贝所有保留属性可能消耗较多内存和时间，请按需选择最少属性。
