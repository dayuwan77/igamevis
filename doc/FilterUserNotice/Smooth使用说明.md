# Smooth 使用说明

## 功能

通过邻接点迭代平滑表面顶点位置，减小局部起伏并调整顶点分布。
生成独立结果，保留原模型；点数、面数、顶点编号、面连接关系和有效属性保持不变。

支持 `SurfaceMesh` 和全部由线性面单元组成的 `UnstructuredMesh`，包括三角形、四边形和多边形。
体网格需要先提取表面；点云、线网格、高阶单元和混合维度网格不支持直接处理。

## 在 iGameVis 中使用

1. 打开模型，在模型树中选中待处理模型。
2. 点击“算法处理 → 数据处理 (Data Processing) → 表面平滑 (Smooth)”。
3. 设置迭代次数、收敛阈值、平滑系数和保留边界，然后点击“应用”。
4. 模型树中新增 `Smooth_1` 等独立结果节点，原模型保留。

重新选中原模型可以按另一组参数生成结果。选中结果节点再执行则继续平滑该结果。
“取消”恢复默认参数并关闭面板，不删除已经生成的结果。
无输入或数据不支持时会提示，不生成结果节点。

## 参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 迭代次数 | 20 | 最大迭代轮数，对应 ParaView 的 Number of Iterations；Qt 范围 0～1000，0 仅生成副本 |
| 收敛阈值 Convergence | 0 | 允许提前停止的位移比例，范围 0～1；0 禁用提前停止 |
| 平滑系数 | 0.01 | 每次向邻接点平均位置移动的比例，范围 0～1；0 不移动 |
| 保留边界 | 关闭 | 开启后固定开放边界；关闭时允许平缓边界点沿边界移动 |


每个可移动顶点使用：

`新位置 = (1 - 平滑系数) × 当前位置 + 平滑系数 × 邻接点平均位置`

每轮按顶点编号依次写回；后面的顶点可以读取本轮前面已更新的位置。
邻接点通过面的边相连，四边形的对角顶点不作为直接邻接点。
孤立点和非流形边的端点固定。

开放边界由只属于一个面的边构成。未开启“保留边界”时，边界点仅使用两个边界邻接点；
分叉、零长度边及转角超过 15° 的边界点仍固定。15° 对应 VTK 默认 Edge Angle。

收敛检查在每轮结束后进行：
当本轮最大实际顶点位移不超过 `Convergence × 输入包围盒对角线长度` 时停止。
`GetNumberOfIterationsPerformed()` 返回实际完成的轮数。

## 代码调用

```cpp
#include <Smooth/iGameSmoothFilter.h>
#include <iGameFileIO.h>

auto input = iGame::FileIO::ReadFile("Models/mazewheel.obj");
auto filter = iGame::SmoothFilter::New();
filter->SetInput(input);
filter->SetNumberOfIterations(20);
filter->SetConvergence(0.0);
filter->SetRelaxationFactor(0.01);
filter->SetPreserveBoundary(false);
if (filter->Execute()) {
    auto output = filter->GetOutput();
}
```

这里使用默认的 20 次迭代。
`Execute()` 成功返回 `true`；失败返回 `false`，通过 `GetMessage()` 查看原因。
每次执行从当前输入开始，先清空旧输出；失败后不会返回上次成功的结果。

## 注意事项

- 较多迭代可能导致收缩和细节损失，建议先从 20 或 200 次开始观察。
- 属性数值仅独立复制，不插值或重新计算；已有坐标、法向、曲率等几何相关属性可能需要另行更新。
- 每个面限制为 3～32 个互不重复的有效顶点，每个顶点最多 255 条邻接边，每条边最多关联 255 个面。
- 非有限坐标、越界顶点编号、错误的单元类型数量、非法参数和超限数据会失败。
